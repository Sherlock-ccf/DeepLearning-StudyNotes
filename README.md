# 模式识别学习文档

## 前言

**关于为什么要写这个文档**

今天是2026年11月18日，其实我从很早之前就想写这篇文档，那是我刚接触机器学习、深度学习之类的东西，感觉一切都十分新奇：机器竟然可以通过一串代码将诸多规律与数据学习到参数中；后来经过一定的学习实践，感觉这一切又不是那么神奇了，这不过是数学公式在作祟罢了，计算机学家和数学家设计了一套巧妙的算法让参数通过迭代的方式变得符合要求；再后来接触到Transformer之类的东西，我逐渐意识到，这机器学习竟然如此神奇，似乎无法解释。——这大概就是，看山还是山、看水还是水吧。

过去碍于种种原因让我迟迟没有把这篇文档写出来，但现在我终于愿意提笔开写了——因为模式识别的考试近在咫尺了，我想把这样一篇文档写出来：一方面，像梳理乱线一样将自己杂七杂八的学到的东西整合起来，另一方面，可以用作复习材料，还有一方面，练习打字。没错，笔者的打字速度很慢，正好借此机会提升一下打字速度。

**关于这个文档里有什么**

正如前文所言，笔者希望让这篇文档能够很好的梳理自己的思路，所以除了有关相关书籍《机器学习》（西瓜书）和《模式识别》（红书）之外，笔者还会结合一点自己的思考和一些直观的代码。当然，AI时代下，大模型也会帮助笔者完成自己思路的梳理。
